导入模型容量数据

点击选择 CSV 文件或拖拽文件到此处

原型支持 CSV 导入演示；真实系统可对接 Excel 解析。已使用量建议由研发接口回写，不建议人工导入维护。

导入规则：

1. 无 id：系统生成新 id，并新增记录。

2. 有 id 且系统中存在：按 id 更新已有记录。

3. 有 id 但系统中不存在：导入失败，提示 id 不存在；如需新增，不应填写 id。

4. RPM/TPM 总量可导入；已使用量从研发接口获取；可分配量由系统计算。
